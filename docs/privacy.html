Breeze 개인정보처리방침

시행일: 2026년 11월 18일 · 운영: Pierrot Company, Inc. (피에로컴퍼니)

피에로컴퍼니(이하 “운영자”)는 Breeze 브라우저(데스크톱·모바일 앱, 이하 “Breeze”)를 제공함에 있어 이용자의 개인정보와 시청 프라이버시를 최우선으로 보호합니다. 본 방침은 Breeze가 어떤 정보를 처리하고, 어떤 정보를 저장하지 않으며, 이용자가 어떻게 자신의 정보를 삭제할 수 있는지 설명합니다.

1. 수집 및 처리하는 정보

  • Google 계정 로그인 정보: 이용자가 자막 기능을 켜기 위해 Google 계정으로 로그인할 때, Google OAuth의 기본 비민감 범위(email, profile)를 통해 이메일 주소, Google 계정 식별자, 기본 프로필 정보를 인증 서비스(Supabase Auth)에서 처리합니다. Breeze는 Google Drive, Gmail 등 민감한 Google 데이터에 접근하지 않습니다.
  • 무료 이용 시간 원장 및 중복 차감 방지 기록: 계정별 일일 무료 이용 시간(기본 15분/일, KST 자정 초기화) 계산과 되감기·재시청 시 중복 차감 방지를 위해 일일 사용 시간(초)과 영상 URL·제목이 포함되지 않은 서버 비밀 키 기반 익명 미디어 지문(HMAC-SHA256) 및 5초 단위 재생 구간 버킷을 처리합니다.
  • 인증 및 운영 로그: 인증 제공자(Supabase)의 자체 인증 감사 로그(로그인·토큰 갱신 시점의 이메일, IP 등) 및 운영자 관리 API 호출 로그가 인증 시스템에 남을 수 있습니다.

2. 서버에 저장하지 않는 정보 (비저장 원칙)

  • 방문 URL · 영상 제목: Breeze 프록시 서버와 원장 데이터베이스는 이용자가 방문한 사이트 주소, 페이지 제목, 영상 파일 주소를 수집하거나 로그에 기록하지 않습니다.
  • 영상 · 오디오 · 자막 내용: 자막 생성 및 번역을 위해 전송되는 오디오 프레임과 사이트 자막 텍스트는 실시간 AI 처리(Google Cloud Vertex AI)에만 일시 사용된 뒤 즉시 폐기되며, 서버 디스크나 애플리케이션 로그에 저장되지 않습니다.
  • 크래시 리포트: 앱 오류 및 크래시 진단 기록은 이용자 기기에만 남으며 외부 서버로 자동 전송되지 않습니다.

3. 이용자 기기(로컬)에만 저장되는 정보

  • 시청 기록, 이어 보기 위치, 즐겨찾기, 사이트 자막 번역 캐시(원문 자막 파일 식별 해시·번역문·마지막 사용 시각) 및 무URL 로컬 음성 자막 캐시(mediaFp:pin 기준 번역 자막과 용어집)는 서버로 동기화되지 않고 이용자 기기에만 저장됩니다.
  • 앱 내 기록 지우기(지난 1시간 / 오늘 / 전체)로 로컬 기록과 자막 캐시를 지울 수 있습니다. 다만 URL을 저장하지 않는 무URL 음성 자막 캐시 구조상 개별 방문 기록 1건 삭제만으로는 지워지지 않으며 범위 삭제 시 함께 삭제됩니다.
  • 시크릿 창 / 시크릿 모드에서 이용한 기록·쿠키·번역 캐시는 디스크에 저장되지 않고 종료 시 즉시 삭제됩니다.

4. 제3자 서비스 처리 및 위탁

  • Google Cloud (Vertex AI / Cloud Run): 음성 인식 전사 및 한국어 자막 번역 처리, 웹·프록시 서버 호스팅
  • Supabase: Google OAuth 로그인 세션 관리 및 무료 사용 시간 원장 저장

5. 보유 기간 및 계정·정보 삭제 방법

  • 계정 정보: 이용자가 계정을 삭제할 때까지 보관하며, 계정 삭제 즉시 인증 계정 정보가 삭제됩니다.
  • 5초 단위 재생 구간 버킷(익명 미디어 지문): 생성 후 3일 이내 자동 삭제됩니다.
  • 계정 삭제 방법: 앱 내 사이드바 → 계정 → 계정 삭제를 두 번 누르거나, 웹 Breeze 계정 삭제 페이지에서 Google 로그인 후 즉시 삭제할 수 있습니다.
