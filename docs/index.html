실시간 한국어 자막과 자체 플레이어로

Breeze는 자막 파일이 없는 영상이나 해외 생방송까지 실시간으로 인식·번역해 한국어 자막을 띄워 주는 미디어 브라우저입니다. Google 계정으로 로그인하면 하루 15분까지 무료로 자막 기능을 이용할 수 있습니다.

오픈 베타 안내: 매일(KST 00:00 기준) 계정당 15분 무료로 자막이 제공됩니다. 상용 DRM(Widevine 등)이 적용된 영상과 YouTube는 자체 플레이어에서 제외되며 원래 화면 위 자막으로 안내됩니다.

핵심 특징

선행 · 실시간 AI 자막

VOD는 앞서 분할 전사·번역해 대사와 딱 맞춰 보여 주고, 라이브 방송도 실시간으로 한국어 자막을 띄웁니다. 원어 고정(자동 · 일본어 · 영어 · 한국어), 글자 크기, 위치, 원문 병기를 지원합니다.

자체 플레이어 & 이어 보기

HLS · DASH · MP4/WebM · MSE 영상을 깔끔한 전용 플레이어에서 0.25x–4x 배속, 트랙 선택, 항상 위(PiP), 이어 보기로 감상할 수 있습니다.

프라이버시 우선 설계

영상 URL·소리·자막 원문·번역은 서버에 저장하지 않고, 시청 기록과 북마크는 사용자 기기에만 보관합니다. 시크릿 모드를 닫으면 세션 데이터가 즉시 지워집니다.

첫 실행 안내 (비서명 베타 빌드)

베타 기간 중 별도 유료 코드 서명 없이 배포되므로, 처음 한 번만 OS 보안 경고를 허용해 주세요.

  • macOS (DMG): Breeze.app을 응용 프로그램 폴더로 복사한 뒤, 첫 차단 시 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 누릅니다.
  • Windows (EXE): SmartScreen 창이 열리면 추가 정보 → 실행을 클릭합니다.
  • Android (APK): 설치 시 출처를 알 수 없는 앱 설치 허용을 켭니다. 이후 새 버전은 앱 내 사이드바 → 계정 → 업데이트 확인에서 받을 수 있습니다.
